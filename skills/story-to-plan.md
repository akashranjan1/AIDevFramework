# Story-to-plan skill

Read the Jira issue and repository before proposing changes. Extract acceptance criteria, non-functional requirements, dependencies, affected Salesforce metadata, test scenarios, permissions/sharing impact, deployment dependencies, and rollback approach.

Return assumptions/questions, ordered implementation steps, affected files, Apex/LWC/Flow test cases, validation commands, risks, deployment notes, and criterion-to-test traceability. Do not change code before plan approval.
